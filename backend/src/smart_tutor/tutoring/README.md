# `tutoring` module (Release 1)

**Owns** (PRD §9.2, US-3, US-4 to US-6, US-13): Threads (no subjects; they keep their documents used (US-4b)), relevance gate, the ask path, conversation management.

**Key classes:** `Thread`, `Turn`, `RelevanceGate`; services `AskService`, `ConversationService`; ports `Retriever`, `ThreadRepository`.

**Built so far:** `Thread` and `ThreadRepository` (`SqlThreadRepository`); `ConversationService.require_documents` / `start_thread(user_id, question)` (a learner with no ready, non-archived document gets "Upload a document first"; the title starts as the first question); `update_thread` (`Thread.rename`: trimmed, 1–120 characters, refused while archived; also `search_scope`, `library` or `listed`, which limits the search to the conversation's documents (US-4c); `search_documents` reads the ids; removing the last listed document turns the limit off); `Retriever` with its MCP client adapter `McpRetriever` (`search(query, k, document_ids=None)` over all of the learner's ready documents, or only the given ones); `covers` and `LIMITED_DECLINE` (a limited search with no chunk at or above `answer_floor` is declined, US-4c); `answer_messages` / `cited_chunks` (the quoted answer prompt and its citations); documents used: `ConversationService.record_turn` (adds a kept turn's documents in order of first use, no duplicates) and `documents_used` (resolved now: title, authors, year, archived, or "Deleted document"), stored as `ThreadDocument` rows. The learner's additions and removals (`add_documents`, only their ready, non-archived documents; `remove_document`); rows record `added_by`. `ConversationService.keep_deleted_title(user_id, document_id, title)` copies a document's title onto its rows in that learner's threads just before the document is deleted. Conversation history: `ConversationService.record_turn` keeps a turn whose answer ended with `done` (question, answer, citations as ids and page, or the decline) with its documents used in one transaction, as `Turn` rows (`thread_turns`); `turns` reads them oldest first through owner-scoped SQL and resolves citations now (title, archived, or "Deleted document"). `AskService`, `RelevanceGate`, and conversation management are still to come.

**May use (application layer only):** `knowledge` (whether the learner has a ready document), `subjects`, `accounts`, `insights` (log declines). Everyone may use `shared`.

**Rules:** Never reads chunk tables: retrieval goes through the `Retriever` port (MCP client adapter). A thread has no subjects and answers from all of the learner's ready documents. Document text is passed to the model as quoted data. Never imports `learning`.

Layout: `domain/` → `ports/` ← `application/`, `adapters/`. Other modules import only `tutoring.application`.
