**Goal:** Give the web app its permanent frame (design tokens, light/dark theme, left nav with routing, user-menu slot, four base components, and a static empty Library) so every later slice drops its screen into it.

**Architecture:** Tokens live once in `web/src/styles/tokens.css` as CSS variables, ported from the accepted prototype at tag `design-v0.3`. One nav config (`web/src/app/nav.ts`) drives both the side nav and the route table (`web/src/app/routes.tsx`); `createBrowserRouter` serves it in the app and `createMemoryRouter` in tests.

**Tech Stack:** React 19, TypeScript 7, Vite 8, React Router 8, lucide-react 1, Vitest 5 + jsdom + Testing Library.

**Spec:** issue #39 (`gh issue view 39`) and `DESIGN.md` (repo root). Design states `components@v0.3` and `library-empty@v0.3`.

## Global Constraints

- Feature and component CSS uses only `var(--…)` tokens from `tokens.css`; a missing value is added to `tokens.css` for both themes first.
- Never paste prototype HTML, JS, or CSS rules into `web/src/`. Token **values** are copied verbatim (they are data); component styles are rewritten as CSS Modules.
- Leave out the review chrome: `--chrome-*`, `--review-h`, `.rb-*`, `od-*`.
- Theme: `data-theme` on `<html>` follows `prefers-color-scheme`; no theme switch.
- Laptop only: `body { min-width: 1024px }`; no breakpoints.
- Nav order and labels, verbatim: Library, Chat, Conversations, Notes, Subjects, Usage, Settings. No R2/R3 items rendered.
- Icons: `lucide-react`, `strokeWidth={1.5}`, `aria-hidden` unless the icon is the only label.
- Required copy (brief §6.3, prototype `library-empty`): heading "Upload your first document"; text "PDFs up to 50 MB and 500 pages. Your documents stay private to you."; button "Choose PDFs"; Library description "Your documents. They're private to you, and the tutor answers only from them."
- No backend changes. Commit subjects imperative; each commit ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Run every command from `web/` unless stated.

## Review Focus

1. **Deep link or refresh on a nested route** (`/notes` typed in the address bar): the shell renders with Notes current, not a blank page. Covered in Task 3 (`renders the requested page on a deep link`); nginx already falls back to `index.html`.
2. **Unknown path** (`/nope`): the learner lands on Library, not an error screen. Task 3 test `redirects unknown paths to the Library`.
3. **OS theme changes while the app is open:** the page switches theme without reload. Task 1 test `follows later changes`.
4. **Keyboard-only use:** every nav item and button is reachable by Tab and shows a focus outline; the Library's disabled button stays announced as disabled. Task 2 test `is disabled and says so`, Task 3 test `nav items are links`; outline checked visually in Task 4.
5. **Screen-reader users and the state badge:** state is conveyed by text, never color alone. Task 2 test `shows a text label for every state`.

```ts
function fakeQuery(matches: boolean) {
  const listeners = new Set<(e: MediaQueryListEvent) => void>();
  const query = {
    matches,
    addEventListener: (_: string, fn: (e: MediaQueryListEvent) => void) => listeners.add(fn),
    removeEventListener: (_: string, fn: (e: MediaQueryListEvent) => void) => listeners.delete(fn),
  } as unknown as MediaQueryList;
  const change = (dark: boolean) => listeners.forEach((fn) => fn({ matches: dark } as MediaQueryListEvent));
  return { query, change, listeners };
}

describe("followColorScheme", () => {
  it("sets the current OS theme", () => {
    const root = document.createElement("html");
    followColorScheme(root, fakeQuery(true).query);
    expect(root.dataset.theme).toBe("dark");
    followColorScheme(root, fakeQuery(false).query);
    expect(root.dataset.theme).toBe("light");
  });

  it("follows later changes", () => {
    const root = document.createElement("html");
    const fake = fakeQuery(false);
    followColorScheme(root, fake.query);
    fake.change(true);
    expect(root.dataset.theme).toBe("dark");
  });

  it("stops following after unsubscribe", () => {
    const root = document.createElement("html");
    const fake = fakeQuery(false);
    const stop = followColorScheme(root, fake.query);
    stop();
    fake.change(true);
    expect(root.dataset.theme).toBe("light");
    expect(fake.listeners.size).toBe(0);
  });
});
```

```ts
// The app follows the OS colour scheme; a theme switch in the user menu comes later (DESIGN.md → Themes).
export function followColorScheme(root: HTMLElement, query: MediaQueryList): () => void {
  const apply = (dark: boolean) => {
    root.dataset.theme = dark ? "dark" : "light";
  };
  const onChange = (e: MediaQueryListEvent) => apply(e.matches);
  apply(query.matches);
  query.addEventListener("change", onChange);
  return () => query.removeEventListener("change", onChange);
}
```

```tsx
import type { LucideIcon } from "lucide-react";
import type { ButtonHTMLAttributes } from "react";

import styles from "./Button.module.css";

type Props = ButtonHTMLAttributes<HTMLButtonElement> & {
  variant?: "primary" | "secondary" | "ghost" | "quiet";
  size?: "sm" | "md" | "lg";
  icon?: LucideIcon;
};

export function Button({ variant = "secondary", size = "md", icon: Icon, className, children, type = "button", ...rest }: Props) {
  const classes = [styles.button, styles[variant], styles[size], className].filter(Boolean).join(" ");
  return (
    <button type={type} className={classes} {...rest}>
      {Icon && <Icon className={styles.icon} strokeWidth={1.5} aria-hidden="true" />}
      {children}
    </button>
  );
}
```

```tsx
import { ChevronUp, LogOut } from "lucide-react";
import { useEffect, useId, useState } from "react";

import styles from "./UserMenu.module.css";

type Props = { name: string; detail?: string; onSignOut?: () => void };

const initials = (name: string) =>
  name.split(/\s+/).filter(Boolean).slice(0, 2).map((part) => part[0]!.toUpperCase()).join("");

export function UserMenu({ name, detail, onSignOut }: Props) {
  const [open, setOpen] = useState(false);
  const menuId = useId();

  useEffect(() => {
    if (!open) return;
    const onKey = (e: KeyboardEvent) => e.key === "Escape" && setOpen(false);
    document.addEventListener("keydown", onKey);
    return () => document.removeEventListener("keydown", onKey);
  }, [open]);

  return (
    <div className={styles.foot}>
      {open && (
        <div className={styles.menu} id={menuId}>
          <div className={styles.head}>
            <strong>{name}</strong>
          </div>
          {onSignOut && (
            <button type="button" className={styles.item} onClick={onSignOut}>
              <LogOut className={styles.icon} strokeWidth={1.5} aria-hidden="true" />
              Sign out
            </button>
          )}
        </div>
      )}
      <button
        type="button"
        className={styles.user}
        aria-expanded={open}
        aria-controls={menuId}
        onClick={() => setOpen((v) => !v)}
      >
        <span className={styles.avatar} aria-hidden="true">{initials(name)}</span>
        <span className={styles.who}>
          <span className={styles.name}>{name}</span>
          {detail && <span className={styles.detail}>{detail}</span>}
        </span>
        <ChevronUp className={`${styles.icon} ${open ? styles.flip : ""}`} strokeWidth={1.5} aria-hidden="true" />
      </button>
    </div>
  );
}
```
