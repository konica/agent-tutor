# Deployed environments send traces to their LangSmith project (#229) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** On-premise and native-cloud trace asks and ingestion like local runs, each into its own LangSmith project, with keys from Secrets Manager, a configurable sampling rate, the worker's egress allowing LangSmith, and trace retention handled by LangSmith instead of a deletion job.

**Architecture:** #221 already traces each ask (`ask`) and each content's processing (`ingest`) through LangSmith's env-configured default client. This ticket is deployment wiring plus one robustness change: (1) tracing errors are caught at the trace boundary so they never fail the traced work, and a bad LangSmith configuration fails at startup instead; (2) CDK creates the learner-hash key secret and a `trace-sampling-rate` SSM parameter per mode; the operator creates the LangSmith API key secret (CDK can't mint a LangSmith key); (3) on-premise `deploy.sh` renders these into the env file and Compose passes them to the agent and worker, while the worker's Squid allowlist gains `api.smith.langchain.com`; (4) the Helm agent and worker read the same secrets through External Secrets; (5) the end-to-end smoke test can verify the ask's trace; (6) docs: the retention job keeps only the decline log, the PRD says D25 is met by LangSmith's project retention.

**Tech Stack:** Python 3.13, LangSmith SDK 0.14 (`LANGSMITH_TRACING`, `LANGSMITH_API_KEY`, `LANGSMITH_PROJECT`, `LANGSMITH_TRACING_SAMPLING_RATE`), AWS CDK (Python), Docker Compose + Squid, Helm 4 + External Secrets, GitHub Actions.

**Spec:** GitHub issue #229 (parent #220); PRD §10.4, §11, D25; ADR 0012, 0013, 0014. Builds on #221 (`sdd/plans/2026-10-11-ask-run-tracing.md`).

## Decisions (simple defaults)

- **Secret names** (under each mode's secret prefix: `smart-tutor-on-premise/…`, `smart-tutor/…`):
  - `langsmith/learner-hash-key`: generated by CDK (ConfigStack, both modes), 64 chars, no punctuation.
  - `langsmith/api-key`: a LangSmith service key, created by the operator (runbook), like `duckdns/token`. CDK cannot create it.
- **Projects:** on-premise `smart-tutor-on-premise`, native-cloud `smart-tutor-native-cloud`. The worker traces into `<project>-ingestion` (from #221's `ingestion_project()`). The *production project* is on-premise's (the default mode the pilot runs on).
- **On-premise without the API key secret:** `deploy.sh` warns and deploys with `LANGSMITH_TRACING=false`, so merges keep deploying before the operator creates it (same pattern as DuckDNS). **Native-cloud** requires it: its release is opt-in and run by hand after the runbook step.
- **Sampling:** LangSmith's own `LANGSMITH_TRACING_SAMPLING_RATE` (deterministic by trace id). Its value is the SSM parameter `<ssm_path>/trace-sampling-rate` (ConfigStack, default `"1"` = every run, PRD §10.4); on-premise `deploy.sh` and the native-cloud workflow read it at deploy time.
- **Services that trace:** the agent and the worker only (#221). On-premise only the worker is egress-limited, so only Squid changes; native-cloud has no egress NetworkPolicy.
- **Retention:** LangSmith SaaS keeps a trace 14 days (base) or 180 days (extended, the SaaS maximum since 2026-09-14); traces with feedback or in an annotation queue are auto-upgraded to extended. Either way no trace outlives 180 days, which meets D25. The production project is set to **Extended (180 days)** so 4-week quality windows and feedback calibration (§10.2, §12) have data. The retention job keeps only the decline log.

## Global Constraints

- Tokens, raw user ids, and emails never reach a trace, a log line, or deploy output (ADR 0007, PRD §10.4). `deploy.sh` prints no secret.
- Tracing never fails a learner's request or a content's processing.
- Unit tests never reach the network: use `fakes.RecordingClient` or a client subclass; the autouse fixture in `backend/tests/unit/conftest.py` keeps tracing off unless a test turns it on with `langsmith.tracing_context(enabled=True, ...)`.

## Review Focus

1. LangSmith unreachable, rejecting the key, or the client raising during an ask → the learner still gets the full answer and `done` (Task 1 test with a raising client).
2. A sampling rate outside 0–1 or not a number → the agent and worker refuse to start instead of silently tracing nothing (Task 1 test).
3. On-premise deploy before the operator creates `langsmith/api-key` → deploy succeeds with tracing off and a warning naming the secret (Task 3 test).
4. The worker reaching another `langchain.com` host, or LangSmith on a port other than 443 → refused by Squid and caught by `check-egress.py` as a leak (Task 3 tests).
5. A smoke run whose ask is sampled out, or whose trace arrives late → the smoke test polls until the deadline and then fails with a message that names the run id and the sampling rate as a possible cause; it never prints the API key or token (Task 5 tests).

```python
logger = logging.getLogger(__name__)

T = TypeVar("T")


@contextmanager
def never_raising(cm: AbstractContextManager[T], fallback: T) -> Iterator[T]:
    """Runs the block inside `cm`, a trace, but a trace that can't start or end is logged and skipped: tracing never
    fails the work it traces (#229). The block's own errors still propagate."""
    try:
        value = cm.__enter__()
    except Exception:
        logger.warning("tracing could not start; running untraced", exc_info=True)
        yield fallback
        return
    try:
        yield value
    except BaseException as error:
        try:
            cm.__exit__(type(error), error, error.__traceback__)
        except Exception:
            logger.warning("tracing could not end", exc_info=True)
        raise
    try:
        cm.__exit__(None, None, None)
    except Exception:
        logger.warning("tracing could not end", exc_info=True)


def start_tracing(settings: Settings) -> LearnerHasher | None:
    """Startup check for a process that traces: the learner-hash key (see `learner_hasher`), and, while tracing is
    on, LangSmith's own settings, by building the default client now. A sampling rate outside 0–1 then stops startup
    instead of failing every trace."""
    hasher = learner_hasher(settings)
    if ls_utils.tracing_is_enabled():
        run_trees.get_cached_client()
    return hasher
```

```python
class AskTrace:
    def __init__(self, run: RunTree | None) -> None:
        self._run = run  # None: the trace didn't start, so there is nothing to end

    def finish(self, answer: str, decline: str | None, chunks: int) -> None:
        """What the run ended with: a decline gives the model no chunks."""
        self._end(outputs={"answer": answer, "decline": decline}, metadata={"decline": decline or NO_DECLINE, "chunks": 0 if decline else chunks})

    def fail(self, code: str) -> None:
        """The run ended with an error event; the learner saw `code`."""
        self._end(error=code, metadata={"decline": NO_DECLINE, "chunks": 0})

    def _end(self, **fields: Any) -> None:
        if self._run is None:
            return
        try:
            self._run.end(**fields)
        except Exception:  # tracing never fails the ask (#229)
            logger.warning("could not end the ask trace", exc_info=True)
```

```python
def test_leaks_reports_a_proxy_that_lets_another_langchain_host_or_port_through(
    refused: ModuleType, monkeypatch
) -> None:
    monkeypatch.setattr(refused, "_tunnel_status", lambda host, port=443: 200 if "langchain" in host else 403)
    problems = refused.leaks()
    assert any("to CONNECT smith.langchain.com:443," in p for p in problems)  # another name of the same service
    assert any("to CONNECT api.smith.langchain.com:80," in p for p in problems)  # the allowed name, wrong port


def test_unreachable_reports_langsmith(check: ModuleType, monkeypatch) -> None:
    def urlopen(url: str, timeout: float) -> None:
        if "smith.langchain.com" in url:
            raise OSError("Tunnel connection failed: 403 Forbidden")
        raise check.urllib.error.HTTPError(url, 404, "nf", {}, None)  # Bedrock answers

    monkeypatch.setenv("AWS_REGION", "us-east-1")
    monkeypatch.setattr(check.urllib.request, "urlopen", urlopen)
    monkeypatch.setattr(check, "_connects", lambda host, port: True)
    monkeypatch.setattr(check, "_aws_problems", lambda region: [])
    assert check.unreachable() == ["LangSmith: Tunnel connection failed: 403 Forbidden"]
```
