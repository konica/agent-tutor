# Design

The design for Smart Tutor lives here and nowhere else. Process and rules: `sdd/specs/2026-10-03-design-to-code-loop-design.md`.

| Path | What |
|---|---|
| `brief.md` | Design brief, the designer's source of truth. Versioned v0.x (brief §13). |
| `prototype/` | The whole Open Design project (pages, styles, scripts, its version snapshots and frames). Open Design edits this folder in place. Open `prototype/index.html` in a browser to review it; `#/<state-id>` opens one state. |
| `prototype/history/` | Exported Open Design conversations: the designer's questions and the owner's answers. |
| `rounds.md` | Accepted rounds, newest first; each is a git tag `design-v0.x`. Written by `make design-accept` (created on the first accepted round). |
| `states.json` | Index of every state in the prototype: id, group, brief section, description, release, user stories. Generated by `make design-states`; CI fails when it is stale. |

## Commands

Run from the repo root (or run the `npm run design:*` script in `web/` directly). First time: `cd web && npm ci && npx playwright install chromium`.

| Command | What it does |
|---|---|
| `make design-states` | Regenerate `states.json` from the prototype. Run after every prototype change. |
| `make design-accept ROUND=v0.3 FEEDBACK="Q7, D1–D12"` | Record an accepted round: refresh `states.json`, add the row to `rounds.md`, and print the tag command to run after the PR merges. `ROUND` must equal the brief version. |
| `make design-shots STATES="chat-*" [ROUND=v0.3] [THEME=light\|dark\|both]` | Render states at 1440×900 to `.design-shots/<round>/` (git-ignored). Without `ROUND`, renders the working copy. |
| `make design-diff FROM=v0.3 [TO=v0.4]` | List states added, removed and changed between two rounds (or a round and the working copy), and the open issues that cite the removed or changed ones. |

## Working in Open Design

1. In Open Design, import the folder `C:\Data\Projects\agent-tutor\sdd\design\prototype` (the main checkout, never a `.claude/worktrees/` path).
2. Start a round by pasting brief Appendix A with `brief.md` attached.
3. Commit work in progress on a `design/v0.x` branch. A round counts only after it is accepted and tagged.

## For coding agents

- Build from the prototype at the ticket's tag (`design-v0.x`), not the working copy.
- The prototype is a spec, not code to copy. Rebuild it with `web/src/components/` and the design tokens.
- Do not read Open Design or its data folder.
