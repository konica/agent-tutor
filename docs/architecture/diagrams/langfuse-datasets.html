Swimlane · Smart Tutor evals

Create a dataset and publish it to Langfuse

How to

  1. Add sources: PDFs in seed_corpus/manifest.yaml, hand-written examples in datasets/<name>.yaml.
  2. make evals-generate DATASET=ask asks the judge model for candidates and sends each one to the queue smart-tutor-ask-candidates.
  3. Reviewers open the queue in Langfuse and set the accepted score using the rubric in the queue's description.
  4. make evals-publish (add --dry-run first) writes the next version, e.g. smart-tutor-ask/smoke-v4: smoke ≈ 30 items (examples + accepted items, a few of each type), full = examples + every accepted item.
  5. Pin it in the dataset YAML (pins: {smoke: smoke-v4, full: full-v2}). A version is never edited; publish a new one instead. Until #320 the runner reads pins as LangSmith tags, so don't pin a Langfuse version yet.
