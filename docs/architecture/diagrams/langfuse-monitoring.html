Architecture · Smart Tutor observability

Observe traces and monitor metrics

How to

  • Open https://sec-dog.duckdns.org (07:00–18:00 Asia/Ho_Chi_Minh) → project smart-tutor-on-premise → Tracing → Traces. Filter by name (ask, ingest), environment, session (= thread) or user (= learner hash).
  • The ask root carries deployment, chat_model, embedding_model, limited, decline, chunks, thread_id and learner_hash; the ingest root carries deployment, chat_model, embedding_model, learner_hash and content_id. Latency, tokens and model calls come from the LangChain spans.
  • Developers use smart-tutor-local. smart-tutor-evals holds datasets, review queues and candidate traces (environment local); the CI stack is not traced until #320.
  • Privacy: traces carry a learner hash, never a user id, email or token. Production traces must be gone within 180 days; the deletion job is #321.
